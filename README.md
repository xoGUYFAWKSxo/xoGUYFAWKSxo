# Galactic Studio

I make free, open-source Windows tools.

## Projects

- [Galactic Tune-Up](https://github.com/xoGUYFAWKSxo/galactic-tune-up): a free, open-source Windows 10/11 maintenance tool.
- [Galactic Macro](https://github.com/xoGUYFAWKSxo/galactic-macro): record and play back mouse and keyboard macros on Windows.
- [Galactic Downloader](https://github.com/xoGUYFAWKSxo/internet-downloader): a download manager for Windows (early development).
- [Frame Time Doctor](https://github.com/xoGUYFAWKSxo/frame-time-doctor): PC gaming diagnostics from PresentMon captures, with before/after reports.
